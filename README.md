# DrupalX Nonprofit

Nonprofit sample content for DrupalX decoupled Drupal distribution.

## Overview

This package provides nonprofit-focused sample content for the DrupalX decoupled Drupal distribution.

## Features

* Sample nonprofit content
* Example donation pages and layouts
* Demo nonprofit site structure
* Reference implementation

## Requirements

* Drupal 10+
* PHP 8.1+

## Installation

Follow the standard Drupal installation procedure using this installation profile.
